# 🤖 Plantilla de Agente Maestro (Elite AI Agent Template)

Este repositorio contiene un sistema de **bootstrapping** diseñado para configurar automáticamente ecosistemas de agentes de IA especializados en cualquier proyecto de desarrollo. Utiliza una metodología de "Elite Agent" que garantiza calidad, automatización y consistencia desde el minuto uno.

## 🚀 Características Principales

-   **🔍 Descubrimiento Inteligente**: El agente investiga automáticamente en [skills.sh](https://skills.sh) y [mcpmarket.com](https://mcpmarket.com) para encontrar las mejores herramientas según el stack tecnológico.
-   **📅 Workflow por Fases**: Obliga a la IA a dividir el trabajo en hitos claros y realizar subidas mediante **Pull Requests** detallados.
-   **📦 Releases Automáticas**: Integración nativa con `release-please` para automatizar versiones, changelogs y tags en GitHub.
-   **🛡️ Guardrails de Calidad**: Prohíbe la creación de PRs si el código no pasa los tests o el linting. Incluye verificación visual automática (capturas de pantalla) para cambios de UI.
-   **🧠 Memoria de Decisiones**: Mantenimiento automático de un `PROJECT_LOG.md` para documentar la arquitectura y decisiones técnicas.
-   **🇪🇸 100% en Español**: Configurado para que toda la comunicación, commits y releases sean exclusivamente en español.

## 🛠️ Contenido del Repositorio

-   `AGENT_BOOTSTRAP.md`: El **Mega-Prompt** "llave maestra". Copia su contenido y pégalo en tu IA favorita al iniciar un proyecto.
-   `AGENTS.template.md` (Embebido): Plantilla dinámica que sirve de base para el archivo `AGENTS.md` de tus nuevos proyectos.

## 📖 Cómo Usarlo

1.  **Copia el contenido** de `AGENT_BOOTSTRAP.md`.
2.  **Pégalo** en tu asistente de IA (Gemini, Claude, Antigravity, etc.) al iniciar un nuevo repositorio.
3.  **Responde** a las preguntas de descubrimiento que te hará la IA.
4.  **Aprueba** el `AGENTS.md` generado y ¡empieza a construir!
